Methode

Keine Templates. Ein Prozess, der zuhört — und dann baut.

01 / Idee

Zuhören & verdichten

Jedes System beginnt mit einem Gespräch. Was soll passieren, wer nutzt es, was darf es nie tun — bevor eine Zeile entsteht, steht die Absicht.

02 / Struktur

Aus Worten wird Struktur

Aus dem Gespräch wird Architektur: Datenflüsse, Agenten-Rollen, Schnittstellen. Sichtbar gemacht, bevor gebaut wird — damit nichts im Nebel bleibt.

03 / System

Live & messbar

Dann wird gebaut: Voice-Agenten, Automationen, 3D-Interfaces. Deployed, getestet, im Alltag — nicht als Demo, sondern als Werkzeug.

Über

20 Jahre von der Bar zu Bytes. Gastgeber zuerst, Builder aus Überzeugung.

MyFlowMotion ist das Studio von Alex Heyers — Vibe Coder, Solopreneur, Vater. Zwanzig Jahre Gastronomie und Digital haben eine Sache gelehrt: Es geht nie um das Werkzeug, es geht um den Menschen davor.

Deshalb entstehen hier keine Tech-Demos, sondern Systeme mit Haltung: KI-Agenten, die sich vorstellen, bevor sie loslegen. Automationen, die dokumentiert sind. Interfaces, die man ohne Handbuch versteht.

Gebaut wird im Terminal, mit Claude Code — jeden Schritt öffentlich, Fehler inklusive. Learning in Public ist keine Marketing-Idee, sondern die Methode.
